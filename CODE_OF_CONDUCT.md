# Code of conduct

We want Crossfade to be a project where anyone can contribute without harassment or hostility.

- Be respectful and assume good intent. Critique code and ideas, not people.
- No harassment, discrimination, personal attacks, or unwelcome sexual attention, in any project space.
- Keep discussions about the work. Disagreement is fine; contempt is not.

Maintainers may remove comments, commits or contributors that break these rules. Report problems privately to the
maintainers through a GitHub security advisory or the contact listed on the Hinterland Labs GitHub profile.

This code is adapted from the spirit of the Contributor Covenant.
